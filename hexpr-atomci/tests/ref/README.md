# Reference values

`ref_hij.txt` holds matrix elements computed by ATOMCI2's `ac_ci_hij` before the C tools of
ATOMCI2 used this library. It gives the tests of this library a reference that did not come
from it, and lets them run without ATOMCI2.

`make_ref_hij.c` wrote it. Built against the current C tools of ATOMCI2, which now use this
library, it gives the same elements to 3e-15; that is a consistency check, not an independent
one. With `ATOMCI_C` the `c/` folder of ATOMCI2, built:

```bash
cc -O2 -std=c11 -I"$ATOMCI_C/include" -I../../include make_ref_hij.c "$ATOMCI_C/build/libac.a" \
   ../../build/libhexpr_atomci.a -llapack -lblas -lm -fopenmp -o make_ref_hij
./make_ref_hij > ref_hij.new
```

`CFPTBL.sha256` is the hash of the CFPTBL that the Fortran ATOMCI of ATOMCI2 builds (`make` at
the top of the repository). The table generated by this library must match it byte for byte.
